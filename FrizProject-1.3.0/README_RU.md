# FrizProject 1.3.0 — GitHub-ready core

Самостоятельный проект Minecraft Bedrock на Nukkit-MOT. Это не оригинальные исходники, карта или закрытая конфигурация FrizMine.

## Что реализовано в этой версии

- Иерархия персонала: хелпер → модератор → старший модератор → администратор → старший администратор → куратор → разработчик → создатель → владелец.
- Роль `creator` имеет wildcard-доступ ко всем проверкам прав этого плагина. Ей доступны административные телепорты, установка должностей/привилегий и `/beacon spawn`.
- Администратор имеет только явно выданные ему права: `/stafftp`, `/tphere`, `/tpall` и базовые модераторские действия, перечисленные в `ranks.yml`.
- `/coords` показывает координаты, `/coords on|off` включает/выключает координаты в action bar.
- `/stafftp`, `/tphere`, `/tpall` — служебная телепортация.
- `/beacon spawn` — просит сервер поставить блок-маяк в текущей позиции игрока через `setblock`.
- `/staffrank` и `/rankset` — назначение должности и донат-ранга (только роль с `friz.staff.rankset`, по умолчанию creator/owner).
- `/kit` и `/kits` — наборы утилитарных ресурсов с 24-часовым кулдауном. Состав в `kits.yml` самостоятельный и не содержит PvP-оружия.
- `/staffchat` — закрытый чат персонала.
- GitHub Actions автоматически собирает JAR после push/pull request.

## Что не включено

- Точные составы закрытых наборов FrizMine: на публичном сайте опубликованы названия китов и доступы привилегий, но не полный перечень предметов каждого кита.
- Боевые эффекты сфер/талисманов. В открытых объявлениях FrizMine подтверждается, что сферы и талисманы перерабатывались, но полный актуальный каталог с характеристиками в проверенных публичных источниках не опубликован. В этой версии не копируются их боевые свойства.
- Команды, перечисленные в публичном магазине FrizMine, но не реализованные обработчиками этого плагина (например `/fly`, `/grant`, `/invsee`, `/fixall` и другие). Их нельзя считать работающими только потому, что названия есть в публичном списке.
- Готовая карта `.mcworld` и оригинальный спавн FrizMine.

## Требования

- Java 21+
- Maven 3.9+
- Nukkit-MOT release `1.26.50-R1` (или обновите зависимость под свою точную сборку)

## Сборка локально

```bash
mvn clean package
```

Готовый файл появится в `target/frizproject-core-1.3.0.jar`.

## Публикация через GitHub

1. Создайте пустой репозиторий GitHub, например `frizproject-core`.
2. Распакуйте этот архив.
3. На странице репозитория нажмите **Add file → Upload files** и загрузите всё содержимое папки проекта (включая `.github`).
4. Нажмите **Commit changes**.
5. Откройте вкладку **Actions** и дождитесь зелёного статуса workflow `Build FrizProject`.
6. Откройте завершённый запуск workflow, внизу скачайте artifact `FrizProject-1.3.0`.
7. Поместите JAR в папку `plugins` тестового сервера Nukkit-MOT и перезапустите сервер.

## Первый запуск и настройка ролей

После первого запуска появятся `plugins/FrizProject/ranks.yml`, `users.yml`, `kits.yml`, `kit-cooldowns.yml`.

В консоли сервера или от имени игрока с ролью creator/owner:

```text
/staffrank Nick helper
/staffrank Nick moderator
/staffrank Nick administrator
/staffrank Nick creator
/rankset Nick overlord
```

Роль `creator` — техническая роль твоего проекта, не официальная привилегия FrizMine. Не выдавай её обычным игрокам.

## Команды этой версии

```text
/coords [on|off]
/stafftp <игрок>
/tphere <игрок>
/tpall
/beacon spawn
/staffrank <игрок> <роль>
/rankset <игрок> <привилегия>
/kits
/kit <название>
/staffchat <сообщение>
```

## Важное замечание о совместимости

Код ориентирован на текущую документацию Nukkit-MOT и его Maven release dependency. В этой среде Maven не установлен, поэтому фактическая компиляция здесь не запускалась. GitHub Actions выполнит сборку после загрузки проекта. Сначала проверьте JAR на тестовом сервере и резервной копии мира.
