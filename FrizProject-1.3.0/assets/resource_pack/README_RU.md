# Ресурспак (черновик)
Иконки в `textures/items` — авторские концепт-текстуры. Для реального отображения custom items необходимо добавить корректные item_texture.json, atlas/definitions под выбранный Bedrock API и связать предметы с серверным плагином. Одна папка текстур не подключает предметы автоматически.
